# 图片裁剪编辑器工具

入口：`Tools/GameFrame/Art/Image Crop`。Project 中选中一张或多张图片，也可以通过右键 `GameFrame/Image Crop` 打开。实现位于 `GameFrame.Editor`，不进入 Player。

## 操作

1. 选中图片后打开工具，或使用“同步选中”“追加选中”“添加图片”调整列表。
2. 选择裁剪方式、Alpha 阈值及保留边距。边距按原图像素计算，限制在原图范围内。
3. 选择缩放方式，点击“更新预览”。左侧绿框表示裁剪范围，右侧为实际输出；预览使用列表首张，每张批量图片单独计算尺寸。调整处理设置后需要重新更新预览。
4. 指定 Assets 内的已有输出目录，点击“裁剪并导出”。单张可指定文件名，缺少 `.png` 时自动补上；批量使用原文件名加 `_crop.png`。

默认输出副本。勾选“原地覆盖源图”时仅接受 PNG。覆盖任何已有文件前会确认；覆盖无法通过 Undo 恢复。写入已有 PNG 时保留 `.meta`、GUID 和导入设置，新图片使用 Unity 默认导入设置。

## 裁剪规则

| 方式 | 行为 |
| --- | --- |
| 仅透明边 | 以 Alpha 大于阈值的像素确定最小内容框，默认阈值 24，边距 2 像素 |
| 自动 | 存在 Alpha 小于 250 的像素时按透明边处理；否则从边缘以八邻接连通识别近白 / 近黑空白，再取其余像素的内容框 |
| 不裁剪 | 保留原画布，可用于只缩放或处理全透明图片 |

自动模式沿用 `unitygame` 工具的主要黑白判定：RGB 最小值 ≥185 或最大值 ≤70，且最大值与最小值之差 ≤40。它只定位裁剪框，保留框内原像素，不移除背景。主体本身为黑白色且与边缘相连时，也可能被当作空白，应查看预览或改用“仅透明边”。不透明纯黑白图无法区分主体时保留全图；透明图在当前阈值下没有可见内容时明确报错。

## 缩放规则

所有缩放保持裁剪结果的宽高比，不拉伸、不补透明画布。

| 方式 | 行为 |
| --- | --- |
| 不缩放 | 直接输出裁剪后的像素 |
| 指定宽高 | 等比装入目标宽高框，实际输出可能小于指定尺寸 |
| 锁定宽度 / 高度 | 指定一边，另一边由裁剪后的比例计算 |
| 相对原图比例 | 原文件宽高乘以比例得到目标框，再将裁剪结果等比装入；与参考工具的比例语义一致 |

尺寸四舍五入，最小为 1 像素。PNG / JPG / JPEG 均从磁盘原文件解码，因此 Unity 的纹理压缩、Max Size 和 Read/Write 设置不影响处理。输出统一为 PNG；缩放使用浮点预乘 Alpha 的 Lanczos 过滤，避免透明像素中的 RGB 污染边缘。

## 与参考工具的区别及失败语义

参考为 `/Users/zzq/unitygame/Assets/Scripts/Editor/UiImageFinalizeWindow.cs` 及其调用的 `finalize_ui_png.py`。本工具直接在 Unity 内执行，无 Python、Pillow 或 NumPy 依赖；输出目录允许整个 Assets，不固定为 Assets/Art。参考脚本按内容最大边的 2% 计算安全边距、会忽略部分灰色阴影并在缩放后再次裁透明边；本工具使用可配置固定边距，保留灰色阴影，不二次裁剪，让预览尺寸与导出尺寸一致。参考脚本的额外锐化没有迁移。

批量执行前检查源文件格式、输出目录、文件名、重复目标和意外覆盖选中源图。运行时遇到错误立即停止后续图片，处理结果和 Console 报告错误，已成功写入的文件保留，不自动重试或回滚。

临时解码与结果纹理由窗口或单次导出操作拥有，替换预览、关闭窗口和结束导出时释放。工具在 Editor 主线程执行，超大图片的解码、过滤和预览可能占用较多内存与时间。
